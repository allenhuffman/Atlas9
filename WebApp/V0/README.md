# V0 — Atlas9 mobile fan guide (prototype)

Snapshot of the original, Template-built app.

- **Version:** 1.8.18
- **Live at:** https://parkhopping.com/a9/
- **Data source:** the "Atlas9 Dossier — Template" Google Doc
  (rooms and people generated from the Template; phone numbers from
  the Atlas9 Telephone Directory spreadsheet).
- **Contents:** `index.html` (the whole app), `rooms.json`,
  `people.json`, `phones.json`, `telephones.json`, `version.json`,
  `.htaccess`, `build-*.py` (the Template/Directory generators),
  `transcripts/` (the 16 phone-recording transcripts that are inlined
  into `phones.json`).

This is a snapshot, kept for reference. The current app is in `../V1/`.
