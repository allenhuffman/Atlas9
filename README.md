# Atlas9 Projects

This repository contains two projects related to Atlas9:

## Telephone Simulator

A browser-based simulation of a landline phone system. Choose a phone, pick up
the receiver, and dial a number to play its recording.

See [TelephoneSimulator/README.md](./TelephoneSimulator/README.md) for setup,
usage, and data-file details.

## Font Translator

A browser-based Mossman Script writer. Type text to render it in the script,
then download it as SVG or PNG, or print it.

To run it locally, start a web server from `FontTranslator/writer`:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Then open <http://127.0.0.1:8000/>. See
[FontTranslator/writer/README.md](./FontTranslator/writer/README.md) for
instructions on using the writer and editing its glyphs.

The `FontTranslator/recognizer` experiment is not included in this repository
yet; it is still being worked on and does not work reliably.
